Follow one depth frame to the screen

Your tangible win: after this lesson, you can point to the exact boundary responsible when Robot View lists no camera, cannot start one, shows a frozen frame, or paints misleading colors.

Current tree: 0b24fde Skill: trace a frame Prerequisite: basic React
The short answer. The app does not play the returned RTSP URL. With “彩色深度” enabled, it activates the camera source, fetches the source’s snapshot endpoint repeatedly, decodes each response as an image, recolors its 8-bit canvas pixels, and schedules the next fetch 125 ms after the current frame finishes.

The frame route

  1. Connection HostRobot-mode startup stores the Robot Controller IP.
  2. Gateway :8083Lists sources and exposes source-specific control and image paths.
  3. Electron mainFetches JSON or binary data outside the renderer.
  4. HTML ImageDecodes one snapshot response into pixels.
  5. CanvasNormalizes luminance and paints the false-color frame.

Robot-mode startup writes ws://<connection-host>:1234. The API adapter takes that WebSocket URL’s hostname and builds http://<connection-host>:8083 for the camera gateway. Opening the camera modal immediately requests GET /api/v1/sources; the response supplies every source-specific snapshot, preview, start, and stop path.

Activation is not playback

Start controls the gateway

The Start button sends POST source.paths.start. A successful response marks the source active and may return an RTSP URL. The UI stores that URL only to display it in a read-only field.

Rendering chooses another path

The selected renderer depends on source type and the “彩色深度” toggle. The returned RTSP URL is never assigned to a <video> element or decoder.

What “彩色深度” really means

  1. The desktop main process downloads the snapshot bytes and returns a MIME type plus base64 data to the renderer.
  2. An HTMLImageElement decodes those bytes; a canvas draws the image and reads an RGBA Uint8ClampedArray.
  3. The code treats transparent pixels and luminance values at or below 4 as invalid, painting them black.
  4. It builds a 256-bin luminance histogram, takes the current frame’s 2nd and 98th percentiles, and normalizes valid values between them.
  5. Each normalized value is interpolated across a purple → blue → cyan → green → yellow → orange → red palette.
Do not read the colors as meters. Canvas exposes 8-bit display channels, and this code rescales them independently for every frame. A red pixel means “high within this frame’s visible luminance range,” not a stable physical distance. Raw or metric depth semantics would need a different data contract.
