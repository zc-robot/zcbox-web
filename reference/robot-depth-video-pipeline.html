Colored-depth loop

fetch snapshot bytes through Electron IPC
  → base64 data URL
  → decode with HTMLImageElement
  → drawImage(canvas)
  → getImageData() as 8-bit RGBA
  → ignore alpha=0 and luminance≤4
  → find luminance p02 and p98
  → normalize + interpolate palette
  → putImageData()
  → wait 125 ms after completion
  → repeat while active
Semantic limit: displayed color is relative per-frame luminance, not calibrated metric depth. The effective rate is below 8 fps because request, decode, and processing time precede the 125 ms delay.
